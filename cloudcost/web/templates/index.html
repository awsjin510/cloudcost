⚠ 最重要的認知陷阱

看到某家配額最大，不代表「這個模型在那家跑最快」。配額只決定扛得住多少，不決定跑得多快。

Capacity（配額）RPM / ITPM / OTPM。決定尖峰時會不會被 429 節流，可提報申請調升。本頁算的就是這個。
Performance（效能）TTFT / TPS 等延遲指標，本頁不涵蓋。同一個模型在各平台的單次回應速度不由配額決定，需要用你自己的提示詞實測。

用實際用量校正 以 PoC／試用期的真實數據取代情境估計

從用量主控台（Anthropic Console、OpenAI Usage、Google AI Studio、xAI Console…）把一段期間的總量填進來，工具會反推每次請求的 token 組成、快取命中率與每人使用頻率，並重新試算上方所有結果。數字只在瀏覽器裡計算，不會送出。
